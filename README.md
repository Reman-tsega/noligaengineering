# Noliga Engineering Website

A responsive business website for Noliga Engineering PLC, a renewable energy and electromechanical engineering company based in Addis Ababa, Ethiopia.

## Project Overview
This project is a static, modern website designed to present the company’s profile, services, projects, and contact information in a polished and professional way. It is built primarily with HTML, CSS, Bootstrap, and JavaScript, and includes animated sections, a gallery-style project display, and a contact-focused layout.

## What the Website Includes
- A welcoming home page with strong branding and call-to-action sections
- An About page describing the company’s mission and expertise
- A Services/Projects page highlighting renewable energy solutions
- A Contact page for inquiries and communication
- Responsive design for desktop and mobile users

## Key Technologies
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Animate.css, WOW.js, Owl Carousel, and Lightbox for enhanced UI experience

## Project Structure
- index.html – homepage
- about.html – company information
- service.html – services and project showcase
- contact.html – contact page
- css/ – custom styling
- js/ – site scripts
- lib/ – third-party libraries and assets
- img/ – images and visual content

## Getting Started
Because this is a static website, you can preview it locally by opening the project folder in a browser or using a live server extension such as VS Code Live Server.

## Purpose
The overall goal of this codebase is to provide a professional online presence for Noliga Engineering, showcase its renewable energy capabilities, and make it easy for potential clients and partners to learn about the company and get in touch.
